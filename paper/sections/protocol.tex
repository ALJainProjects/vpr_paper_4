\subsection{Pre-registration and its history}
\label{sec:protocol}
The protocol is an internal, version-controlled document, signed in dated
stages and committed with the code; it is not deposited in a public
registry, so its timestamps are those of the repository history. Stage~A fixed
the thresholds of Sec.~\ref{sec:gate}, the window and its two secondary sweep
values, the database scope, the comparator, the zoo and the case split before
the data were acquired; an AI coding assistant proposed these values and the
protocol owner approved them. Stage~B recorded, after acquisition and before any
descriptor was computed, the facts only the files could give (format, image
counts, the unusable case, the unanswerable queries). It was drafted from the files by the same
assistant, and the protocol owner countersigned it before the test
gate, which the gate runner enforced. The AnyLoc-GeM wrapper was written
after Stage~B and before any Colon10k descriptor was computed; its parameters,
which the protocol had not fixed, were recorded unchanged before the test
gate.

Nothing was tuned on the validation cases; their readout was
informational, and the runner computes no outcome on them. At the gate window,
on \res{val-nans} answerable queries from \res{val-ncases} cases, all
\res{val-nbeat} of \res{val-nzoo} members beat chance and \res{val-nnontriv}
were non-trivial, the pattern the rule maps to \texttt{OWNER\_REVIEW}. After
seeing this readout, and before any test case was scored, the owner added two
rules that the protocol had left open, chosen from options the assistant
proposed. (i)~If the test gate returned
\texttt{OWNER\_REVIEW}, the paper would report that outcome as its headline
and continue as a diagnostic study. (ii)~If the run crashed after writing its
one-shot lock, one re-run would be allowed only if no gate quantity had been
written. No threshold, window, comparator, zoo member or split was changed,
and the secondary windows stayed non-gating. The gate then ran once on the
test cases from a clean commit; the runner refuses path overrides, writes
the one-shot lock before scoring and verifies the vendored code it imports,
and the gate record it wrote (the lock's content and the decision file's
hash) was committed. Its protocol source is
\texttt{\res{gate-protocol-source}} (Sec.~\ref{sec:gate}).
